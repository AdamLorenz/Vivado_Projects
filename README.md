# Vivado Projects

This repo contains my personal Vivado project folders and local IP block repo:

## Loopback Project
Impliment a loopback adder into the FPGA fabric of a PYNQ-Z2, connect it via AXI protocol to onboard PS, and configure development board with exported bitstream.

Credit to [kbralten](https://github.com/kbralten) and his repo [pynq_to_zynq](https://github.com/kbralten/pynq_to_zynq) which helped guide me through the learning process of using Vivado.
